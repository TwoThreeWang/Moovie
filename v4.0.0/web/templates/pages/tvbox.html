TVBox 配置指南

TVBox 是一款开源的安卓视频播放应用，支持导入第三方数据源。通过配置本站提供的 API 地址，你可以在 TVBox 中搜索和播放 Moovie 影牛聚合的影视资源。

什么是 TVBox？

TVBox 是一款基于开源项目 TVBoxOSC 的安卓视频播放器，支持通过 JSON 配置文件接入各种影视数据源。常见的 TVBox 类应用包括：

  • TVBox（原版 / 各修改版）
  • FongMi（蜂蜜）影视
  • OK影视
  • 影视工场
  • 其他兼容 TVBox 配置格式的应用

这些应用都支持相同的 JSON 配置格式，只需填入一个配置地址即可使用。

配置步骤

  1. 安装 TVBox 类应用

    在安卓设备上安装任意一款支持 TVBox 配置格式的视频应用。

  2. 进入配置界面

    打开应用后，找到 「设置」 或 「配置」 入口（通常在右上角菜单或侧边栏中）。

  3. 粘贴配置地址

    在 「配置地址」 输入框中，粘贴以下地址：

    {{ .TVBoxAPIURL }}
  4. 确认并加载

    点击 「确定」 或 「加载」，应用会自动拉取配置并加载数据源。

  5. 开始使用

    配置成功后，在首页即可看到 Moovie 影牛的数据源，支持浏览分类、搜索影片、在线播放。

功能说明

  • 热门推荐：首页展示豆瓣热门电影、电视剧、综艺、动漫。
  • 分类浏览：支持按电影、电视剧、综艺、动漫分类浏览。
  • 搜索播放：输入关键词搜索影片，点击即可在线播放。

常见问题

配置后显示「没找到数据」？

请确认：

  • 配置地址是否完整复制（以 /api/tvbox.json 结尾）
  • 网络是否正常，能否在浏览器中打开该地址
  • 如果使用的是较旧版本的 TVBox，建议更新到最新版

点击影片后无法播放？

本站的播放源来自第三方资源网站，部分影片可能因为资源失效而无法播放。可以尝试：

  • 返回搜索结果，选择其他同名结果
  • 更换关键词重新搜索

在 iPhone 上能用吗？

TVBox 类应用目前仅支持安卓系统。iPhone 用户可以使用本站网页版搜索和播放。

配置示例

不同应用的配置入口位置可能略有不同，但操作方式一致：

设置 → 配置地址 → 粘贴地址 → 确定

通用配置流程

配置成功后，返回首页即可看到数据源列表，选择 Moovie 影牛即可开始使用。
